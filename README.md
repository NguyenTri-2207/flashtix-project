# ⚡ FlashTix - High Traffic Event Booking Platform

![AWS](https://img.shields.io/badge/AWS-Level%20Architecture-orange)
![Docker](https://img.shields.io/badge/Container-Docker-blue)
![Status](https://img.shields.io/badge/Status-Development-green)

**FlashTix** is a cloud-native ticketing platform designed to handle high-concurrency traffic during "flash sale" events. This project demonstrates the migration from a monolithic architecture to **AWS ECS Fargate** with Auto-scaling capabilities.

## 🚀 Key Features
- **High Availability:** Zero downtime during traffic spikes.
- **Auto-Scaling:** Automatically provisions containers based on CPU load.
- **Cost Optimization:** Serverless compute (Fargate) model.
- **DevOps:** Automated CI/CD pipeline using GitHub Actions.
